# 🛒 E-commerce Sales & Customer Analytics (MSSQL)

## 📌 Project Overview

This project simulates a real-world e-commerce database system using Microsoft SQL Server. It is designed to manage customers, products, orders, and payments while generating meaningful business insights.

---

## 🎯 Problem Statement

E-commerce businesses often struggle to:

* Identify top customers and products
* Track revenue trends
* Monitor order status
* Detect low stock or operational issues

This project solves these problems using SQL-based analytics.

---

## 🛠️ Tools Used

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)

---

## 🧱 Database Schema

The database consists of the following tables:

* Customers
* Categories
* Products
* Orders
* OrderItems
* Payments

---

## 🔗 Relationships

* One customer can place multiple orders
* One order can contain multiple products
* Each product belongs to a category
* Each order has a payment

---

## 📊 Key SQL Concepts Used

* Joins
* Aggregations (SUM, COUNT)
* GROUP BY
* Views
* Stored Procedures
* Functions
* Triggers
* Indexing
* Error Handling (TRY...CATCH)

---

## 📈 Business Insights Generated

* Top spending customers
* Monthly revenue trends
* Best-selling products
* Pending orders
* Low stock alerts

## ▶️ How to Run

1. Open SQL Server Management Studio
2. Run schema/create_tables.sql
3. Run data/insert_data.sql
4. Execute queries from queries folder
